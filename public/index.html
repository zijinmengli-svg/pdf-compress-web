01 / PREPARE

Start with the limit, not the smallest number.

Try 10MB first for a design portfolio PDF. If the application allows 20MB, use the larger limit to give project images and fine type more room. For a strict 5MB, 2MB, or 1MB limit, expect more visible trade-offs.

Upload your PDF, enter the target size, then download and review the result. Figma, InDesign, and presentation exports can all contain oversized images.

02 / REVIEW

Check the pages people will study.

Compare the cover, small captions, UI screens, and full-bleed imagery at 100% zoom. If details soften, shorten the portfolio before forcing a much smaller file.

03 / KEEP

Preserve the structure.

TinyPDF aims to retain page count, dimensions, and layout while working toward your target. Some PDFs cannot reach an exact size or keep every image equally sharp.

04 / SHARE

Ready for the next step.

Use the reviewed file for a job application or email attachment. Files are processed temporarily and normally deleted after about one hour; no account is required.
