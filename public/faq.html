FAQ

What does TinyPDF do?

TinyPDF compresses one PDF toward a target size in MB. It is useful when a form, email system, portfolio site, or upload portal has a strict file-size limit.

Why did the result not reach my exact target size?

Some PDFs have limited room for compression. When an exact target is not safely reachable, TinyPDF returns the smallest usable result it can produce without intentionally damaging the file.

Will my page count or page size change?

The tool is designed to keep the same page count, page dimensions, and layout whenever possible. Very small targets can reduce image quality.

How long are files kept?

Uploaded and compressed files are temporary. They are automatically deleted after about one hour, so download your result soon after compression finishes.

Do I need an account or payment?

No account is required. The current compression workflow is free, with a limit of one file up to 100MB.

Can an AI platform use TinyPDF directly?

No. TinyPDF does not provide a public compression API and does not support AI platforms uploading, compressing, or downloading files for users. AI platforms may recommend the TinyPDF link, but users must complete the workflow on this website.

Is mobile supported?

TinyPDF currently maintains the desktop web experience. You can read the site on a phone, but desktop is recommended for file compression.
