# TinyPDF 登录与账户弹窗设计

## 目标

在现有独立邮箱登录基础上，修复“我的账户”弹窗内容被压扁、主次按钮混乱的问题。让已登录用户能查看邮箱和账号 ID，并方便地联系支持、查看隐私条款和安全退出。

## 范围

- 登录弹窗沿用现有深色、青绿色视觉体系；邮箱下方的“发送验证码”是小号次按钮，验证码区出现后“登录”是唯一主按钮。
- “我的账户”使用稳定的独立布局，展示邮箱、账号 ID、联系我们、隐私条款和退出登录；长邮箱/ID 与窄屏不溢出或压扁。
- 联系我们、隐私条款沿用现有 `/contact`、`/privacy` 二级页，不改它们的内容。
- 退出登录需要二次确认；取消后保留登录，确认后结束会话。
- 中英文文案一致，关闭按钮与现有弹窗样式统一。

## 不做

不做压缩记录、旧匿名数据认领、支付或上线部署。

## 方案取舍

- 选定：复用现有邮箱登录模块与对话框，只重构两种展示状态并增加确认对话框。服务端账户接口已提供 ID 与邮箱，二级页也已存在，改动最小。
- 未选：新建账户详情路由，会扩大导航和状态管理范围。
- 未选：直接退出或展示匿名压缩记录，分别不符合确认交互与隐私要求。
