# Phase 2 设计：可复用展示广告位（TinyPDF 试验）

**日期：** 2026-06-01
**一句话目标：** TinyPDF 保持 100% 免费（宣传钩子），变现做一个**与广告网络解耦、可一键复制到未来产品**的展示广告位；先无占位上线、并行申请 AdSense、过审后填 ID 即切真广告；全程优雅降级。真正交付物是"可复用的展示广告变现管线"，TinyPDF 是第一个试验场。

---

## 1. 背景与关键决策

- 副业定位：睡后被动、低维护、可复制到多个小工具。本产品用来**跑通流程**。
- 模式：**展示广告**（不是订阅、不是一次性付费、不是激励解锁）。
  - 订阅/一次性付费：对"偶尔用一次"的 PDF 工具转化差，违背"免费即卖点"。
  - **关键约束（已确认）**：AdSense **网页端没有激励视频格式**，且**禁止诱导看广告**（incentivized views → 封号风险）。所以"看广告解锁大文件"的奖励门**不能用 AdSense**，本期退掉。
- 现状脚手架：`index.html` 有"看广告解锁大文件"弹窗、`app-simple.js` 有 `if(ADS_ENABLED && isLarge)` 拦截分支——均为休眠占位，本期**移除**。

## 2. 组件与改动

### 2.1 退掉旧奖励门
- 删除 `public/index.html` 的 `#ad-modal` 整块弹窗 + "Toast（无广告模式降级）"相关（若仅服务奖励门）。
- 删除 `public/app-simple.js` 中：广告弹窗 DOM 引用、`openAdModal`/倒计时逻辑、`AD_WATCH_SECONDS`、以及压缩入口处 `if (ADS_ENABLED && isLarge) {…}` 分支（改为：所有文件直接进入压缩，无门槛）。
- 保留 `LARGE_FILE_MB` 仅用于服务端 GA `pdf_upload` 的大文件需求记录（不再拦截前端）。
- 保留 `ADS_ENABLED`（语义改为"是否注入展示广告"）。

### 2.2 可复用展示广告位组件（核心交付物）
- 新建 `public/ad-slot.js`（自包含、无业务耦合，可整段拷到下个产品）。
- HTML：在主内容区**结果区之后**插入一个容器 `<div id="ad-slot-main" class="ad-slot"></div>`，**默认 `display:none`**。
- 初始化（读 `/api/config` 的广告字段，见 2.4）：
  - **未启用 / 无 `adClient`** → 不注入任何脚本、容器保持隐藏（`display:none`），**不占空间**。
  - **启用且有 `adClient`** → 注入 `<ins class="adsbygoogle" data-ad-client data-ad-slot data-full-width-responsive="true">` + 异步加载 `pagead2.googlesyndication.com` 脚本并 `(adsbygoogle=window.adsbygoogle||[]).push({})`。
  - **成功渲染才显示**：监听 `<ins>` 的 `data-ad-status`；约 3 秒后若为 `unfilled`、或脚本 `onerror`/超时未加载（GFW 被墙）→ 容器**保持隐藏、不占空间**（等价于未启用）。仅当 `data-ad-status="filled"` 时把容器设为可见。
- 该组件对外接口：`initAdSlot(containerId, {adClient, adSlot, enabled})` —— 复用到别的产品只需换 `adClient/adSlot`。

### 2.3 位置与样式
- 广告位容器在 DOM 中位于**结果卡片之后**：结果隐藏时它紧贴主工具卡片下方；结果出现时自动落到结果卡片下方——**永远在当前卡片栈的最底部**（纯 DOM 顺序实现，无需 JS 重定位）。
- 宽度与主工具卡片**左右对齐一致**：放进与卡片同一个居中容器、`width:100%`、同 `max-width`。
- 仅在真广告 `filled` 时显示，故不会出现空白占位。

### 2.4 配置（env，复用现有模式）
- `AD_ENABLED`（已存在，bool）、新增 `AD_CLIENT`（如 `ca-pub-xxxx`）、`AD_SLOT`（广告单元 ID）。
- `/api/config` 响应新增：`adClient`、`adSlot`（`adsEnabled` 已存在）。空字符串表示未配置。
- Railway 改环境变量即生效，无需改代码。过审拿到 ID 后填上即出真广告。

### 2.5 CSP 放行（必须，否则广告 JS 被自身安全头挡掉）
- 现状 `setSecurityHeaders` 为 `script-src 'self'`。
- 改为**动态**：
  - `AD_ENABLED=true` 时，向 `script-src`/`frame-src`/`img-src` 增补 Google 广告域名：`https://pagead2.googlesyndication.com`、`https://googleads.g.doubleclick.net`、`https://tpc.googlesyndication.com`、`https://www.google.com`（及 `img-src` 的 `https:` data:）。
  - `AD_ENABLED=false` 时维持当前严格 CSP。
- **同时确认现有 GA 代理域名** `https://analytics.tinypdf.cn` 在 `script-src`/`connect-src` 中被允许（实现时核查 CSP 是否真的作用于静态 HTML——目前法务页就从该域名加载 gtag）。

### 2.6 法务页改写（AdSense 过审要求 + 与现状对齐）
- `public/terms.html` 与 `public/privacy.html` **当前内容陈旧**（描述已删除的"每日免费 3 次 + 看广告换 10 次额外次数 + localStorage 配额"）。沿用其现有规范结构，**改写内容**为：
  - 免费政策：**完全免费、不限次数**；去掉每日配额/看广告换次数/localStorage 计数的所有表述。
  - 广告：**展示广告（Google AdSense）**；第三方 Cookie、个性化广告说明、Google 广告设置/退出链接（`https://www.google.com/settings/ads` 与 `https://policies.google.com/technologies/ads`）。
  - 统计：GA4 经第一方代理 `analytics.tinypdf.cn` + 服务端 Measurement Protocol；第一方 `tinypdf_cid` cookie（区分用户、2 年）。
  - 文件处理（临时存储 ≤1 小时自动删除）、不存内容、HTTPS 等保留并核对准确。
  - 更新"最后更新"日期为 2026-06-01。
- 原创撰写，不照抄任何外部参考站文本（版权）；属模板性质，建议用户自行复核。

## 3. 不做（YAGNI / 搁置）
- 不接真实 AdSense 单元（等账号过审给 ID；本期只到"占位/降级 + 可切换"）。
- 不做多广告位、不做自家轮播占位（明确要求"无占位"）。
- 不做付费/订阅/激励解锁。

## 4. 验证计划
- **禁用态**（`AD_ENABLED` 未设）：页面无任何外部广告脚本；广告容器 `display:none` 不占空间；CSP 维持严格；大文件直接免费压缩、无弹窗。
- **启用 + 假 client**（本地设 `AD_ENABLED=true AD_CLIENT=ca-pub-test AD_SLOT=123`）：注入 `<ins>` + 脚本；CSP 含 Google 域名；因无真账号 `unfilled` → 容器保持隐藏不占位（验证降级）。
- **退门回归**：移除奖励门后，>40MB 文件直接压缩、无 modal；现有压缩功能与单测 7/7 不受影响。
- 法务页：人工通读，确认无"每日次数/看广告换次数"等陈旧表述，含 AdSense/Cookie 声明。

## 5. 复用到下一个产品的方式（模板价值）
- 拷 `public/ad-slot.js` + 容器 div + `/api/config` 的三个广告字段 + CSP 动态放行那段 + 法务页广告声明段落。换 `AD_CLIENT/AD_SLOT` 即用。
