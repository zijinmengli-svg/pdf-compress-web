1. Service Description

TinyPDF is a web-based utility for compressing one PDF file to a target size in MB. The service is designed to preserve page count, page dimensions, and layout whenever possible.

  • TinyPDF supports single-file PDF compression.
  • TinyPDF does not provide PDF merging, splitting, editing, OCR, signing, or format conversion.
  • The current workflow is intended for desktop browsers.
